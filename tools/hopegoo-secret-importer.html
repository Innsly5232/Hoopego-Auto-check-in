Hopegoo 账号配置导入

选择签到 HAR，生成 GitHub Actions 需要的账号配置。文件在当前浏览器内处理，本页面不发送网络请求。查询 HAR 为可选项。

签到文件应包含 performCheckin；同一域名、同一会话的多条签到记录可以一起导入。自动签到不需要查询文件；如额外提供 listCheckin，两个文件各保留一条对应记录。

请选择签到 HAR 文件。

校验成功后，点击“复制账号配置”，再打开 GitHub 的 New repository secret 页面。 Name 填写下方名称，Secret 粘贴复制的配置，然后保存。

Secret 名称：HOPEGOO_ACCOUNT_01

复制内容包含登录会话。请粘贴到 GitHub Secrets，不要贴到聊天或提交到仓库文件。本页不会验证云端登录、签到或会话有效期。
